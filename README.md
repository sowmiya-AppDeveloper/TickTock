# TickTock
## Timer Management
# Overview
This is a simple React Native app for managing timers. The app allows users to:

Create and manage timers.
Group timers by categories.
Perform bulk actions on timers (start, pause, reset).
Track the history of completed timers.

## Features
### Timer Creation & Management: 
 Create timers with a name, duration, and category.
### Grouping & Bulk Actions: 
Group timers by categories and perform bulk actions like starting, pausing, and resetting timers.
### Progress Visualization: 
Track timer progress and visualize it in real time.
### History Tracking:
Track completed timers with their names and completion times.
